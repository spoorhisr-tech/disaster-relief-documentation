# Disaster Relief and Emergency Management System

## Project Overview

The Disaster Relief and Emergency Management System aims to help manage disaster events, emergency requests, incident reports, resources, shelters, and volunteers through a centralized application.

## Key Features

- Disaster Event Management
- Emergency Request Management
- Incident Report Management
- Resource Management
- Resource Allocation and Distribution
- Shelter Management
- Volunteer Management
- Dashboard and Reports

## Technology Stack

- Backend: Laravel (PHP)
- Database: MySQL
- Local Development: XAMPP
- API Format: REST with JSON
- Version Control: Git and GitHub
- Cloud Services: To be confirmed with the project guide and team
